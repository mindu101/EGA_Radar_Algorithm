# 基础 06 · 动手实验指南

> 7 个小实验，每个 30~100 行、只依赖 `numpy + opencv + scipy`，
> **不需要 ROS2、不需要 GPU、不需要雷达**。全部能在这台机器直接跑。
> 每个实验都是项目某个模块的「去工程化」最小复刻——跑完再回头看真实代码，
> 会产生「哦，就是这个」的效果。

## 环境

```bash
cd learning/basics/experiments
python3 -c "import numpy, cv2, scipy"     # 三个包都在系统 python3 里（Ubuntu 自带或 pip 装即可）
python3 exp1_ply_overview.py              # 这样跑
```

输出图片统一存到 `experiments/output/`。

## 每个实验看什么

**实验 1 · PLY 与俯视图**：手写二进制 PLY 读取器（30 行），把项目自带的
104 万顶点场地网格读出来画俯视图。看点：z 范围 -0.2~2.4 m——大片蓝是地面，
红黄一圈是环形高墙。这张图就是雷达眼中的世界。

**实验 2 · 正向投影**：用**项目真实内参**（从 `device.yaml` 抄的 fx=3299.5），
把场地角点、地面点阵、悬空墙顶投影到一张「虚拟照片」。看点：
① 地面等距点阵在照片上越远越密（透视 = 除以 Z）；
② 画面中心畸变只差 1~3 px、边缘差上百 px；
③ 6mm 镜头 62° 视场根本拍不全 28 m 场地——贴边架设的真实约束。

**实验 3 · solvePnP 标定**：合成真值外参 → 投影关键点 → 加 1.5 px 噪声 →
走项目同款 `solvePnPRansac(EPnP) + solvePnP(ITERATIVE)` 反解。看点：
相机位置误差 **0.6 cm**、反投影场地误差 1~7 cm。理解「为什么要人工在环标定」。

**实验 4 · 欧式聚类**：造 5 车 + 1 无人机 + 噪声的合成点云，体素网格 + BFS
实现聚类（PCL `EuclideanClusterExtraction` 的本质）。看点：末尾的 tol 对照
——0.3 / 0.5 / 1.6 m 三档，粘车与碎车的两难一眼看懂。

**实验 5 · 二维卡尔曼**：复刻 `KalmanFilter2d`（同款 F/H/Q/R 结构）。
看点：原始测量 RMSE 0.45 m → 卡尔曼 0.35 m；**目标消失后纯 predict 续航 7 秒**
误差只有 1.3 m。改改 `q_std` 感受调参。

**实验 6 · 匈牙利匹配**：4 个视觉轨迹 × 5 个雷达聚类，建代价矩阵 →
`linear_sum_assignment` → 2 m 门限拒配。看点：末尾贪心法演示「两个轨迹抢
同一个点」，理解为什么全局最优分配不可替代。

**实验 7 · ICP 配准**：2D 版「雷达怎么知道自己在场地哪」——最近邻关联 + SVD
求刚体变换，迭代收敛（残差 29 cm → 2.5 cm）。看点：初值偏 15° 时收敛到
局部极小值失败——这正是项目 **GICP 粗配给 NDT 当初值** 两阶段设计的原因。

## 改实验的建议

每个脚本顶部常量（噪声大小、阈值、初始偏差）都是故意暴露出来给你改的：

- 实验 3：把点击噪声从 1.5 px 加到 5 px，看误差怎么恶化；
- 实验 4：把两台车挪到 0.8 m 间距，tol 要多小才能分开？
- 实验 5：把 `q_std` 从 4.0 改成 0.4，看急转弯时滞后多少；
- 实验 7：把初值偏差从 4° 改成 8°，找出还能收敛的边界。
